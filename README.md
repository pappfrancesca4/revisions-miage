# Révisions MIAGE

App de révision hors ligne (PWA) pour iPhone : Outils probabilistes, Angular/MEAN et Communication for Business.

- Cours expliqués simplement + fiches détaillées
- QCM du prof avec explication de chaque réponse, et centaines de questions de révision
- Cartes « Citez… » pour Communication for Business
- Fonctionne en mode avion une fois installée (Safari → Partager → Sur l'écran d'accueil)

Les fichiers servis sont à la racine (`index.html`, `sw.js`, `manifest.webmanifest`). Les sources sont dans `src/` ; `python3 build.py` régénère `dist/pwa/index.html`.
